## Customization Guidelines

1. **Knowledge Level Adaptation**:
   - If beginner: Start with fundamentals, include more foundational chapters
   - If intermediate: Skip basics, focus on intermediate-advanced topics
   - If advanced: Focus on advanced concepts, specialized topics, or deeper dives

2. **Goal-Based Customization**:
   - Academic focus: Emphasize theory, proofs, comprehensive coverage
   - Career focus: Emphasize practical applications, industry-relevant topics
   - Personal interest: Can be more flexible, include interesting tangents
   - Certification: Focus on exam-relevant topics and practice

3. **Topic Emphasis**:
   - Prioritize chapters/topics the student expressed interest in
   - De-emphasize or skip topics they're not interested in
   - Adjust chapter order if it makes more sense for their goals

4. **Resource Selection**:
   - Beginner: More introductory resources, step-by-step tutorials
   - Intermediate: More challenging resources, deeper dives
   - Advanced: Research papers, advanced textbooks, specialized content

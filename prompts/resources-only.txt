# Course Resources Generator

Generate learning resources for the chapter "{{CHAPTER_TITLE}}" in the course "{{COURSE_NAME}}".

Return ONLY a JSON object with this structure:

{
  "textbooks": [
    {
      "title": "Book Title",
      "author": "Author Name",
      "edition": "Edition info",
      "whyUseful": "Why this book is useful"
    }
  ],
  "freeVideosOrLectures": [
    {
      "source": "Platform name (e.g., YouTube, Khan Academy)",
      "topic": "Topic covered",
      "url": "URL or search term",
      "description": "1–2 sentence explanation of how this video/lecture helps the student learn the topic."
    }
  ],
  "articlesOrDocs": [
    {
      "title": "Article/Resource Title",
      "url": "URL or search term",
      "description": "1–2 sentence explanation of what this resource covers and why it is helpful."
    }
  ]
}

Generate 2-3 textbooks, 3-5 video/lecture resources, and 3-5 articles/docs.

Return ONLY valid JSON, no additional text.
